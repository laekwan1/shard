# Shard (옛 버전 — 창 두 개)

창 통합 이전의 모습입니다. 설정 창과 브라우저 창이 따로 뜹니다.

- 설정·전원은 그려진 창(egui)
- 영상 받기는 별도의 브라우저 창

**더 이상 새 기능이 들어가지 않습니다.** 지금 쓰는 것은 위 폴더의
`Shard/shard.exe` — 한 창에 홈·브라우저·보관함·설정이 모두 들어간 것입니다.

## 왜 남겨 두는가

새 창에서 무엇이 달라졌는지 견주어 볼 것이 필요할 때를 위해서입니다.
기능은 새 쪽이 전부 갖고 있습니다 — 마지막까지 옛 창에만 있던 차단 검사도
새 설정 화면으로 옮겼습니다.

## 실행

`shard-classic.exe`. 관리자 권한이 필요합니다. `WinDivert.dll`과
`WinDivert64.sys`가 같은 폴더에 있어야 합니다.

파일 이름의 `classic`이 두 창으로 뜨게 하는 표시입니다 — 이름을 바꾸면 새
창으로 뜹니다.
