## 바로 이어서 할 것

**폰 화면 구조를 PC와 같게 맞추는 일은 하지 않기로 했다.** 지금 구조(브라우저가
첫 화면, 보관함은 그 위에 덮이는 화면)를 그대로 두고 보관함 UI만 다듬는다.
따라서 옛 계획의 1(홈 화면)·2(주소창)는 **버린 항목**이고, 3·4·5는 끝났다.

남은 것은 아래 "그 다음"이다. 보관함에서 더 손볼 것이 보이면 그때 정한다.

### UI 다듬기 — 조사한 것이 있다

2026-08-16에 UI 트렌드를 조사해 [UI-현대화.md](UI-현대화.md)에 정리했다. 무엇을
어떤 값으로 바꿀지, 무엇을 하지 말지가 순서대로 적혀 있다. 손대기 전에 읽는다.

### 손대면서 눈에 띈 것 (급하지 않음)

- 전체화면에서 좌우 가장자리를 쓸어 밝기·소리를 바꿀 때 뜨는 게이지는 재생바와
  따로 논다. 같이 뜨고 같이 사라지는 편이 자연스럽다.
- `nowPlaying`(음악 바)과 `videoBar`(영상 바)는 버튼 구성이 같아졌지만 여전히
  레이아웃이 둘이다. 하나로 합칠 수 있다 — 다만 배경(스크림 대 판)이 다르다.

## 배포 (진행 중)

순서: **안드로이드 릴리스(Shard 완료) → iOS → PC 설치배포**, Shard 먼저 Veil 나중.
자세한 것과 잃어버리면 안 되는 서명 키는 [배포.md](배포.md).

지금까지: Shard 안드로이드가 디버그 APK에서 **서명된 R8 릴리스(6MB, 버전 자동
증가)**로 바뀌었다. 배포물 `release/android/Shard/Shard.apk`가 그것이다.

다음: iOS 가능성 상세 조사, 또는 Veil 안드로이드에 같은 릴리스 설정 적용.

## 그 다음

**Veil 속도 개선.** 손댈 곳은 짐작이 가지만(전송 계층, 혼잡 제어, 서버 위치,
다중 연결) **먼저 무엇이 느린지 재는 것**이 순서다. 왕복 시간인지, 암호화
처리인지, 연결 수립인지에 따라 답이 완전히 달라진다.

**폰 차단 검사.** 폰 엔진은 소켓 수단으로 우회하므로 전략 목록이 PC와 다르고,
결과를 Kotlin으로 넘길 C ABI도 없다. 폰용으로 다시 짜야 한다.
— 다만 **폰의 우회는 Veil에 맡기기로 했으므로 우선순위는 낮다.**

**옛 UI 정리.** `crates/shard/src/ui.rs`(창 두 개짜리)는 이제 고유 기능이 없다.
당분간 남겨 두되 새 기능은 넣지 않는다.

## 이번에 끝난 것 (2026-08-16)

**폰 브라우저·보관함 (2026-08-16 저녁)** — 파일 목록을 PC처럼 한 줄로(16:9
썸네일 + 길이 배지), 영상/음악 스위치는 미끄러지는 썸으로, 폴더는 PC와 같은
칩으로, 주소창 입구는 4px 막대 대신 도메인 알약으로(스크롤에 물러났다 돌아옴).

**PC** — 보관함 스위치와 폴더 줄 사이의 구분선이 보이지 않던 것. 선 색이 아니라
그 자리에 깔려 있던 4px 크롬색 여백이 원인이었다.

**폰 브라우저** — 페이지를 아래로 당겨 새로고침. SwipeRefreshLayout을 쓰지 않고
액티비티가 흘려보내는 터치를 읽기만 한다(`PullToRefresh.kt`).

**폰 보관함** — 안드로이드 기본 MediaController를 걷어내고 PC 모양의 재생바를
새로 그렸다. 백그라운드·순서대로·무작위·전체화면이 모두 바 안에 있고, 새폴더 옆
⋮ 는 사라졌다. 음악은 파일에 박힌 커버를 영상 자리에 통째로 띄운다.
같이 고친 결함 둘 — 첫 영상이 그림 없이 소리만 나던 것, 빈 선반으로 넘어가면
앱이 죽던 것.

## 그 전에 끝난 것 (요약)

**PC** — 창 통합 마무리. 보관함(선반·폴더·순서 변경·썸네일·커버), 재생기(하단
띠·이전/다음·속도·시크·순서대로/무작위·위치 저장), 설정(초기화·로그 보기·차단
검사), 창(중앙 배치·가장자리 조절·트레이 더블클릭).

**저장 품질** — 프레임을 디코딩 순서로 쓰고 보여줄 시각을 적는다(B프레임 문제),
파일 앞에 탐색 색인, 음악 커버를 파일 헤더 안에.

**네트워크** — `0.0.0.0`은 주소가 아니다: 프로브는 다른 답으로 넘어가고,
전달기는 다음 상위 서버로 넘어간다.

**폰** — 커버를 파일 안에, 재생 위치는 손으로, 목록 순서 끌어서 바꾸기, 중복
다운로드 경고, 상태바 겹침 수정, 헤더에서 제목 빼고 스위치를 최상단으로,
행 메뉴는 이름 바꾸기·삭제만.
