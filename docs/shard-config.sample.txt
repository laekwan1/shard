# Shard 재서명 원격 설정 (설정 계층 1단계) — Veil에 올리는 샘플.
#
# 쓰는 법:
#   1) 이 파일을 Veil 박스에서 정적으로 서빙한다 (예: http://<veil>:6969/shard-config.txt
#      또는 anisette 서버 옆 정적 파일). 값이 바뀌면 이 파일만 고친다 — 앱 재빌드·재설치 불필요.
#   2) 폰의 state_dir에 `config_url.txt`를 두고 그 URL 한 줄을 넣는다(anisette_url.txt와 같은 방식).
#      그러면 재서명할 때마다 앱이 이 파일을 받아 아래 값으로 내장 기본값을 덮는다.
#
# 형식: key=value, 한 줄에 하나. '#'로 시작하는 줄과 빈 줄은 무시. 모르는 키도 무시(앞으로 늘어날 여지).
# 어떤 키가 없으면 그 값은 앱 내장 기본값 그대로 — 부분만 덮어도 안전하고, 받기 실패해도 흐름은 안 깨진다.

# ── 개발자 포털(developerservices2.apple.com) 상수 — 애플이 서버 쪽에서 바꾸면 여기서 고친다 ──
dev_client_id=XABBG36SBA
dev_protocol_version=QH65B2
dev_base_url=https://developerservices2.apple.com/services

# ── anisette 서버(로그인 계층) — 서버가 옮기면 재빌드 없이 여기서 고친다. 비워 두면(또는 이 줄을 빼면)
#    앱은 기존대로 고른다: 사용자가 앱에 넣은 값 > CI 빌드에 심은 값 > 공유 기본. 값을 넣으면 그게 CI
#    빌드값·공유 기본보다 우선한다(사용자 수동값보다는 아래). ──
# anisette_url=http://<veil>:6969

# 앞으로 원격화할 후보(구현되면 키가 늘어난다): GSA 엔드포인트, InnerTube 클라 버전 등.
