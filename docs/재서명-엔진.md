# iOS 자체 서명 엔진 — 설계 (진행 중)

Shard가 **SideStore 없이 자기 자신(과 Veil)을 재서명**한다. 처음엔 Sideloadly로 1회
설치하고, 이후엔 이 엔진이 갱신한다. **repo는 private 유지** — 그래서 **AGPL(SideStore)
코드는 참조·차용 금지**, **공개 프로토콜 + 관대 라이선스 부품**으로만 구현한다.

목표는 SideStore 전체가 아니라 **"서명 + 설치 갱신" 코어 4조각**만 가볍게 넣는 것.

## 왜 이 제약인가 (결정 기록)
- SideStore = **AGPLv3**. 그 코드를 보고 차용·번안하면 파생물 → Shard 전체 공개 의무.
- private을 지키려면 AGPL 코드를 **안 본다**. 대신 **프로토콜(저작권 없음)** 과 관대 부품으로.
- **LocalDevVPN은 못 없앤다**(설치 터널 엔타이틀먼트는 무료 사이드로드 앱이 못 가짐).
  → 최종 앱 구성 = **Shard + LocalDevVPN**(SideStore 제거, 추가 앱 1개).
- 애플 강제 한계는 그대로: **7일 만료**, 만료된 앱은 자가 실행 불가(부트스트랩).

## 4개 부품과 라이선스-안전 재료

| # | 부품 | 무엇 | private-안전 재료 |
|---|---|---|---|
| ① | **서명** | .ipa를 인증서+프로파일로 서명 | **`apple-codesign`(rcodesign, Apache/MPL)** — 순수 Rust, 그대로 |
| ② | **Developer API** | 인증서·App ID·프로파일 발급/갱신 | 우리가 직접 HTTP(엔드포인트는 공개, 베낄 코드 없음) |
| ③ | **anisette** | Apple ID 인증 토큰 | 규격 기반 자체 구현 또는 관대 라이선스 구현. **애플이 자주 깨는 부분 = 유지보수 핵심** |
| ④ | **설치** | lockdownd `installation_proxy`로 설치 | 프로토콜 문서(libimobiledevice가 레퍼런스) + 관대 클라이언트. **minimuxer(AGPL) 코드는 참조 금지** |

④는 **LocalDevVPN 터널 + 페어링 파일**을 경유해 폰의 lockdownd에 닿는다.

## 재서명 = 재설치
재서명은 새 서명이 박힌 .ipa를 만드는 것이고, 그걸 **④ 설치로 다시 설치**해야 유효기간이
연장된다(설치가 기존 앱을 덮어씀). 즉 **재서명 = 재설치**. 실행 중인 인스턴스는 설치 중/후
종료될 수 있다.

## 재서명 타이밍 (사용자 확정)
- **매 실행마다는 안 함**(재설치가 매번 → 느림·낭비).
- **포그라운드/백그라운드 둘 다**에서 인증서 만료를 확인하고, **만료 2일 이내면 자동 재서명**.
  - 포그라운드 진입(콜드 실행 + 돌아올 때마다) → "안 끄고 계속 사용"도 커버.
  - 백그라운드는 **BGTaskScheduler**로 시도 — 단 iOS 백그라운드 실행은 보장이 없어
    **best-effort**(SideStore 자체 백그라운드 갱신도 자주 실패). 그래서 포그라운드 확인이 주,
    백그라운드가 보조.
- **UI — 주소창 오른쪽 모래시계**: 남은 기간 표시, **탭 = 수동 재서명**. 모래시계는 주소창에서
  **한 번 더 오른쪽 스와이프**해 **우회 on/off 토글이 뜰 때 함께** 노출한다(별도 상시 노출 아님).
- **설정**: Apple ID(+앱 암호) 저장. 없으면 모래시계 탭 시 "계정 저장·재서명 안 됨" 알림.
- 자동/수동 **둘 다** 둔다(택일 아님).

## 단계 (PoC → 확장)
1. **① 서명 PoC**: `apple-codesign`로 더미 신원으로 .ipa 서명이 되는지(빌드·서명 메커니즘)
   검증. 크레이트 형태/의존성 무게 확인. — 여기부터.
2. **② Developer API**: 무료 계정 7일 인증서·App ID·프로파일 발급 흐름 구현.
3. **④ 설치**: LocalDevVPN 터널 경유 lockdownd 설치. **실기기 필요** — 실현성의 관건.
4. **③ anisette**: Apple ID 인증. **실현성의 또 다른 관건.**
5. **엔진 통합 + UI**(모래시계·설정·자동 트리거), iOS/Rust 연결.

**③④가 실현성의 핵심** — 서명(①)은 확실하니, 착수 후 ③④를 일찍 실증한다.

## 규모
수 주짜리 독립 프로젝트. 엔진 결합(Shard+Veil UI)보다 우선(사용자 지시).
빌드/검증은 **실기기(iOS)** 가 있어야 ③④가 검증된다 — PC 헤드리스로는 ①②까지.
