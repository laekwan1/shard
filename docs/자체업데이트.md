# 자체 업데이트 채널 (설정 계층 2단계) — 앱스토어 없이 코드 갱신

애플이 **서명·설치 코드 자체**를 바꿔(설정 계층으로 못 덮는 층) 재서명이 깨질 때, 또는 그냥 새 기능을
배포할 때, **CI가 최신 미서명 ipa를 GitHub Release에 올리고 앱이 받아 사용자 인증서로 재서명·설치**해
코드까지 갱신한다. 앱스토어·PC 없이. 같은 번들ID로 in-place 업그레이드라 **다운로드 파일·라이브러리 등
앱 데이터는 보존**된다(만료로 앱이 죽으면 스스로 못 살아나는 부트스트랩 한계는 그대로 — 그땐 PC 1회).

**시크릿도, 폰 설정도 없다.** 마커·ipa URL이 공개·고정이라 앱에 하드코딩돼 있고, 업로드는 CI 내장
토큰만 쓴다(사용자가 넣을 게 없다 — 요청).

## 동작 (구현됨)

- **CI(`ios-app.yml`)**:
  - 디바이스 빌드에 `CURRENT_PROJECT_VERSION=${{ github.run_number }}` → CFBundleVersion이 빌드마다
    단조증가.
  - "Publish to GitHub Release" 스텝: 고정 태그 릴리스 **`selfupdate`**(prerelease)에 미서명 ipa
    (`Shard-unsigned.ipa`)와 마커(`marker.txt` = `<버전>\n<ipa URL>`)를 `--clobber`로 갱신. `github.token`만
    쓴다(`permissions: contents: write`).
- **앱(`ResignModel.checkForUpdate`)**: 실행(.active)마다 **내장 URL**
  `https://github.com/laekwan1/shard/releases/download/selfupdate/marker.txt`를 GET → 마커의 버전이
  `CFBundleVersion`보다 크면 ipa를 받아 **저장 계정으로 재서명·설치**(`selfUpdateFromDownloaded` →
  `selfUpdate(bundlePathOverride:)`, Rust `resign_selfupdate_blocking`이 입력이 `.ipa`면 재포장 생략).
  완료 시 "앱을 다시 시작해 주세요" 팝업 → 확인=적용. VPN 켜짐·저장 계정 필요, 실행당 1회.
  - `state_dir/update_url.txt`가 있으면 그 URL로 덮는다(다른 채널로 바꿀 때만 — 선택).

## 켜지는 조건 / 처음 한 번

- 이 채널은 **checkForUpdate 코드가 든 빌드**를 한 번 설치하면 그때부터 스스로 최신을 따라간다(이후
  빌드마다 폰이 다음 실행에서 받아 갱신). 그 이전 빌드는 코드가 없어 자동 갱신 안 됨 — 한 번은 수동/현재
  방식으로 설치.
- VPN이 꺼져 있으면 그 실행에선 건너뛴다(다음에 VPN 켜면 갱신). 개발 중 잦은 빌드가 부담이면 VPN을 꺼
  두면 자동 갱신이 안 돈다.

## ⚠️ 저장소를 PRIVATE으로 바꾸면

지금은 **PUBLIC 전제** — 릴리스 자산을 인증 없이 받는다. PRIVATE으로 바꾸면 릴리스 다운로드에 인증이
필요해져 이 채널이 조용히 멈춘다. 그땐: **읽기 전용 토큰(fine-grained PAT, contents:read)을 CI 시크릿으로
앱에 심고**, `checkForUpdate`를 GitHub API(`/releases/tags/selfupdate` + `Authorization`)로 바꾸면 된다
(자산 다운로드도 API로). — private 전환 시 함께 처리.
