# Veil

터널·익명성 관리자. **속도를 지불하고 은폐를 삽니다.** 차단만 뚫는 것이 목적이면 Shard가 더 적합합니다.

## 실행

`veil.exe`를 실행합니다. TUN 어댑터 생성과 방화벽 규칙에 관리자 권한이 필요하며 UAC가 뜹니다.

창 없이 트레이에만 올라옵니다 — **보라색 원** 아이콘입니다.

| 조작 | 방법 |
|---|---|
| 창 열기 | 트레이 아이콘 좌클릭 |
| 연결/끊기 | 트레이 우클릭 메뉴, 또는 `Ctrl+Shift+V` |
| 종료 | 트레이 우클릭 → 종료 |

## 서버 추가

프로필 탭에 공유 링크를 붙여넣으세요. `vless://`, `trojan://`, `ss://`, `hysteria2://`, `hy2://`를 지원하고, 여러 줄이나 base64 구독 본문도 그대로 받습니다.

서버가 없다면 저장소의 `scripts/provision-reality.sh`로 Debian/Ubuntu VPS에 REALITY 서버를 세울 수 있습니다.

서버가 아예 없어도 **Tor 프로필 추가** 버튼으로 바로 쓸 수 있습니다 — obfs4와 snowflake는 기본 브리지가 내장되어 있습니다.

## 프로토콜 선택

| 프로토콜 | 처리량 | 버티는 한계 | 깨지는 지점 |
|---|---|---|---|
| VLESS + REALITY | 85~95% | 능동 프로빙 | 서버 IP 평판과 볼륨만 남음 |
| Hysteria2 | 90~130% | 지문 | UDP 차단 시 사망 |
| Trojan / VLESS | 85~95% | 지문 | 능동 프로빙에 노출 |
| Shadowsocks | 90% | 지문 | 능동 프로빙에 가장 취약 |
| Tor (+브리지) | 1~10 Mbps | 능동 프로빙 | 3홉 지연, exit 차단·캡차 |

Hysteria2가 100%를 넘을 수 있는 것은 혼잡 제어가 대역폭을 강제로 밀어붙이기 때문입니다. 손실률 높은 회선에서는 직결보다 빠를 수 있지만 공용망에서는 비매너입니다. 대역폭 값을 정직하게 넣으세요.

## 킬 스위치

기본값이 켜짐입니다. 터널이 죽은 뒤 사용자가 알아차리기 전까지가 실제 주소가 새는 구간이기 때문입니다.

**코어가 스스로 죽으면 킬 스위치를 일부러 내리지 않습니다.** 그게 존재 이유입니다. 대신 상단에 경고와 `네트워크 복구` / `재연결` 버튼이 뜹니다.

앱 자체가 크래시해도 방화벽 상태는 남습니다. 다음 실행 시 자동 복구하고 알려줍니다 — 인터넷이 안 되는데 이유를 모르는 상황을 막기 위한 장치입니다.

## 브라우저로 Tor 쓰기

Tor 탭에 세 가지가 있습니다.

**브라우저용 Tor** — tor 데몬만 띄웁니다. 터널·TUN·킬 스위치를 건드리지 않으므로 나머지 트래픽은 평소대로 나갑니다. 아래 두 가지를 쓰기 전에 먼저 켜세요.

**Chrome 계열로 Tor 사용** — Chrome·Brave·Edge를 감지해, **그 인스턴스에만** 프록시를 걸고 전용 프로필로 띄웁니다. 시스템 라우팅을 전혀 건드리지 않으므로 **평소 쓰던 브라우저 창은 아무 영향도 받지 않습니다.** `chrome.exe를 터널에서 제외`하는 방식보다 정확합니다. WebRTC의 직접 UDP 경로도 막습니다.

다만 **가려지는 건 IP뿐입니다.** 글꼴·화면 크기·캔버스·시간대·확장 목록 같은 브라우저 지문은 그대로라 추적에는 여전히 노출됩니다.

**Tor Browser** — Firefox 기반만 존재합니다. Chrome 버전은 없습니다. 대신 모든 사용자가 똑같아 보이도록 지문을 표준화하는데, 그건 네트워크 계층에서 해결할 수 없는 부분이라 **익명 브라우징에는 이쪽이 정답**입니다.

실행하면 Veil이 자기 터널을 우회하도록 규칙을 넣습니다(Tor Browser는 자체 tor를 쓰므로 터널에 태우면 Tor over Tor가 됩니다). 이때 프로세스 이름이 아니라 **실행 파일 전체 경로**로 지정하므로, 일반 Firefox는 영향받지 않습니다.

## 익명성에 대하여

자체 VPS는 **검열 회피에는 최고지만 익명성에는 최악**입니다. 가입 정보·결제 수단·단독 사용 IP가 전부 한 사람을 가리킵니다. 조사 권한이 동원되는 상황에서는 보호가 아니라 증거입니다.

신뢰가 필요 없는 유일한 구조는 Tor입니다. 어떤 릴레이도 출발지와 목적지를 동시에 알지 못합니다.

그리고 기술 구성보다 운용에서 훨씬 많이 뚫립니다 — 익명 세션에서의 실명 로그인, 카드 결제, 평소 브라우저 그대로 사용, 세션 혼용.

## 파일

| 파일 | 용도 |
|---|---|
| `veil.exe` | 본체 |
| `sing-box.exe`, `wintun.dll` | 터널 코어와 TUN 드라이버 |
| `tor\` | Tor + lyrebird(obfs4·webtunnel·snowflake) + geoip |

전부 **같은 폴더 구조 그대로** 있어야 합니다.

설정과 로그는 `%APPDATA%\Veil\`에 저장됩니다.
