# UI 개선방안 — 화면 요소별

2026-08-16에 화면을 하나씩 짚어 세웠다. [UI-현대화.md](UI-현대화.md)가 값의
사다리(모서리·모션·표적)를 다뤘다면, 이 문서는 **요소 하나하나의 모양과 자리**를
다룬다. 항목마다 지금 → 문제 → 제안. 끝난 것은 표시한다.

---

## 폰 보관함

### 1. 헤더와 폴더 줄의 연결부

**지금**: [뒤로가기+스위치] / [폴더 칩 줄] / 가는 구분선 / [목록] — 세 층이
각자의 여백을 갖고 떠 있다.
**문제**: 스위치와 폴더 줄 사이에 아무 관계가 그려져 있지 않다. PC는 이미
답을 갖고 있다 — 스위치 아래에 **판(sheet)** 이 있고, 폴더와 목록이 그 판의
내용이다. 폰에는 그 문법이 없어서 폴더 줄이 어디에 속하는지 화면이 말하지
않는다.
**제안**: 폴더 줄과 목록을 한 판으로 묶는다. 구분선은 폴더 줄 아래 하나만.
헤더 세로 여백 6→4dp, 스위치 라벨 세로 여백 9→7dp로 위층을 한 단 얇게.
**난이도**: 소. 레이아웃과 여백만.

### 2. 새폴더 생성 — 아이콘을 칩으로

**지금**: 폴더 줄 오른쪽 끝의 폴더+ 아이콘(22dp 흰색) → 대화상자.
**문제**: 바로 옆의 칩들과 언어가 다르고, 그 줄에서 가장 무거운 것이 됐다.
**제안**: 칩 줄의 **마지막 칩**으로 — 외곽선 칩에 "+ 새 폴더". 만들면 그 자리에
새 칩이 생기니 원인과 결과가 같은 자리에 있다. 대화상자는 유지.
**난이도**: 소.

### 3. 폴더 관리 — 이름 바꾸기가 없다

**지금**: 칩을 길게 누르면 "폴더 없애기" 확인만 나온다.
**문제**: 폴더 이름을 바꿀 길이 아예 없다. 파일에는 있는 기능이다.
**제안**: 길게 누르면 [이름 바꾸기 / 폴더 없애기] 메뉴 — 파일 행 메뉴와 같은
문법. 이름 바꾸기는 미디어 스토어의 폴더 경로 이동이므로 Library에 일괄 이동
함수가 필요하다.
**난이도**: 중. 저장소 코드를 건드린다.

### 4. 뒤로가기 — 손대지 않는다

48dp 표적, 좌상단, 화살표. 표준 그대로이고 표준이 맞다. 남은 것은 안드로이드
predictive back 대응인데, 이 화면은 액티비티가 아니라 뷰라 이득이 없다.

### 5. 목록

- ~~한 줄 행, 16:9 썸네일, 길이 배지~~ (끝)
- ~~행 간격 좁히기~~ (끝 — 세로 여백 10→5dp, 행 46dp)
- 정렬은 최신순 고정. 바꿀 필요가 생기면 그때 폴더 줄 끝에 정렬 칩. **보류**
- 다중 선택(여러 개 삭제/이동)은 필요해질 때. **보류**

### 6. 빈 화면 문구가 폴더를 모른다

**지금**: 폴더를 걸어 비어 있어도 "저장한 영상이 없습니다"라고 말한다.
**문제**: 거짓말이다 — 영상은 있고, 이 폴더가 빈 것이다.
**제안**: 폴더가 걸려 있으면 "이 폴더에는 아직 없습니다"로.
**난이도**: 소.

## 폰 브라우저

### 7. 주소창 입구 — 핸들로 되돌림 (끝)

도메인 알약을 시도했다가 되돌렸다: 페이지 자체의 헤더를 가렸다. **페이지가
이긴다.** 발견성은 핸들+스와이프로 두고, 필요하면 첫 실행에 패널을 한 번
열어 보여주는 것(1회성)으로 푼다. **1회성 안내만 남은 제안.**

### 8. 패널 안 정렬

**지금**: 전원 42dp, 주소창 38dp, 새로고침·보관함 40dp — 한 줄인데 높이가 셋.
상태줄 10sp는 작다.
**제안**: 주변 버튼 40dp 통일, 상태줄 11sp.
**난이도**: 소.

스위치 미끄러지는 썸, 폴더 칩(외곽선/채움), 구분선, 48px 재생 버튼, 반지름·
