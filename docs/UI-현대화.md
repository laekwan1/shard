# UI 현대화 — 조사한 것과 정한 값

2026-08-16에 조사했다. 목적은 유행을 따르는 것이 아니라 **어디가 낡았는지를
값으로 말할 수 있게 하는 것**이다. 여기 적힌 것은 전부 지금 스택에서 닿는다 —
CSS(엄격한 CSP)와 안드로이드 XML·벡터만으로, 의존성 추가 없이, Compose 없이.

조사는 에이전트 셋으로 돌렸다(디자인 시스템 갈래 하나, 재생기 갈래 하나, 종합
하나). 첫 판은 발견마다 심사 에이전트를 셋씩 붙이도록 짜서 96개가 뜰 뻔했다 —
**검증을 팬아웃시키면 조사보다 검증이 비싸진다.**

---

## 지금 어디가 낡았나

색은 이미 한 벌이다. `app.css`의 `:root`가 `--surface:#111318` ·
`--raised:#181b22` · `--muted:#8a92a2` · `--accent:#2dd4bf`를 들고 있고 폰도
같은 값을 쓴다.

낡은 것은 그 아래다.

**반지름에 사다리가 없다.** PC가 5·6·7·8·10·12·14·34px을, 폰이 chip 16dp ·
tile 11dp · segment_pill 11dp · segment_track 14dp · pb_frame 20dp를 쓴다. 두
사다리가 서로 모르고, 부모와 자식이 같은 값을 쓰는 자리도 있다(부모와 자식이
같은 반지름이면 자식이 밖으로 삐져나와 보인다).

**모션이 사실상 하나다.** `.12s`~`.16s`에 기본 ease. 곡선 토큰도 지속시간
등급도 없어서 **색이 바뀌는 것과 크기가 바뀌는 것이 같은 속도로 움직인다.**

**터치 대상이 작다.** PC `#row button`이 30×30px, 폰 재생바가 38~46dp. 48 기준에
못 미친다. 스크러버 손잡이는 hover에서만 나타나고 히트 영역이 16px이다.

**자동 숨김이 3초다.** 업계 기본은 5초다(`CONTROLS_MS = 3_000`).

## 정한 값

### 반지름 — 사다리 하나

`4 / 8 / 12 / 16 / 20 / 28 / 32 / 999`. 폰은 같은 숫자를 `<corners>`로.

| 무엇 | PC | 폰 |
|---|---|---|
| 폴더 칩 | 999px, 높이 28px, 좌우 14px | CornerFull, 32dp, 16dp |
| 파일 행 | 10px | 12dp |
| 16:9 무대·카드 | 20px | 20dp |
| 시트·대화상자 | 28~32px | 28~32dp |

**동심 계산**: 안쪽 반지름 = 바깥쪽 − 여백. 무대 20px에 여백 8px이면 커버는
12px. 폰은 `calc`이 없으니 12dp를 적고 "부모 20dp − 8dp"를 주석에 남긴다.

### 밀도와 글자

파일 행은 PC 44px / 폰 56dp 최소, 좌우 16dp. 홈 전원 스위치만 96~136dp 등급.

파일 행 14/20/+0.2. 폴더 칩·재생기 라벨 14/20/+0.1 weight 500. 시각 표시
12/16/+0.5. **선택된 칩과 재생 중인 행은 굵기만 500→700으로 바꾼다** — 크기를
바꾸면 목록이 다시 흐른다.

### 상태 레이어

hover `rgba(255,255,255,.08)` · focus `.10` · pressed `.10` · drag `.16`.
100ms linear. **절대 튕기지 않는다.**

### 모션 — 지속시간 셋, 곡선 셋

| 무엇 | 지속시간 |
|---|---|
| 누름·hover 틴트 | 100ms |
| 칩 선택, 세그먼트 스위치 | 200ms |
| 화면 전환, 보관함 덮기 | 300~400ms |

집 곡선 `cubic-bezier(0.2,0,0,1)` = `PathInterpolator(0.2f,0f,0f,1f)`.
들어오는 것 `(0.05,0.7,0.1,1)`, 나가는 것 `(0.3,0,0.8,0.15)`.

넘어감(overshoot)은 **위치·크기·반지름에만**, 전원 스위치와 무대에만 —
`cubic-bezier(.2,1.2,.3,1)` / `OvershootInterpolator(1.0f)`.
**색과 불투명도는 넘어감 0.**

### 스크러버

트랙 2px, 손잡이 10px → `:active` 14px, 투명한 48px 히트 띠
(`padding:23px 0; background-clip:content-box`).
재생분과 손잡이 `#2DD4BF` 100%, 버퍼 `rgba(255,255,255,.80)`,
미재생 `rgba(255,255,255,.20)`.

경과 시각은 **200ms 틱으로만** 갱신한다(지금은 `timeupdate`마다 다시 쓴다).
화살표 탐색은 3초 고정이 아니라 `duration/20`.

### 바

높이 60px. 왼쪽 [경과 / 전체], 오른쪽 [전체화면]. 모든 버튼 48×48 최소.
자동 숨김 **5000ms**, 무대 위 pointermove·keydown에서 리셋, **일시정지·탐색
중이거나 포인터가 바 안에 있으면 시작하지 않는다.**

폰은 탭 한 번 = 바 토글(이미 그렇다). PC는 `pointerType === 'mouse'`일 때만
클릭 = 일시정지.

### 깊이

**그림자 없음.** `#0E0E10 → #181b22 → #1F232B` 세 단계와 바 윗변 1px
`rgba(255,255,255,.06)`.

## 무엇부터 — 보이는 효과 대비 위험 순

1. **지속시간·곡선 토큰 3개와 상태 레이어 4개를 CSS 변수로.** 값만 추가, 위험 0
2. **스크러버** 2px / 10→14px / 48px 히트 / 3단 불투명도. 값 교체인데 즉시 보인다
3. **48×48 타겟** (PC 30→48, 폰 38→48), 바 높이 60px과 함께
4. **반지름 사다리와 동심 계산.** 파일 수는 많지만 각각 한 줄
5. **자동 숨김 5000 + 일시정지 유지 + 200ms 틱 + duration/20.** 로직이 바뀌는
   첫 항목 — **회귀 위험은 여기부터다**
6. 굵기로 주는 강조와 타이틀 케이스 헤더. 안전하지만 덜 보인다
7. 누름 모서리 변형. 전원 스위치 하나만. 가장 화려하고 가장 안 급하다

## 하지 않기로 한 것

**`backdrop-filter` 유리 바.** 애플의 규칙은 밝고 다채로운 배경을 전제한다.
`#0E0E10` 위에서는 흐린 회색 얼룩이 되고, 폰은 `RenderEffect`가 API 31+이며
**영상 프레임마다 GPU를 문다.** 톤 3단과 헤어라인으로 대신한다.

**앰비언트 블러 배경.** 같은 이유에 순수 장식.

**전송 버튼을 그림 위로 옮기고 오버플로 메뉴 만들기.** 폰 재생바를 방금 PC
모양으로 맞췄고, 이러면 mini 바와 구성이 갈라진다. 보조 버튼이 다섯을 넘지
않으므로 오버플로가 풀 문제가 없다.

**`androidx.dynamicanimation.SpringAnimation`.** 새 의존성.
`OvershootInterpolator` + `PathInterpolator`로 같은 인상이 난다.

**버튼마다 round/square/pressed 세 모양.** 눌림 한 칸만. 나머지는 유틸리티
앱에서 소음이다.

**크기로 주는 강조, ALL CAPS 회색 헤더, 그림자로 표현한 높이.** 셋 다 2019년
습관이고 각 시스템이 스스로 버렸다.

**아이콘·폰트 파일 추가.** CSP가 막고, 두 벌 관리가 생긴다.

**프레임에 여백 굽기.** `object-fit: contain` / `resize_mode=fit`을 유지하고,
늘리기 대신 확대 토글로 준다.
