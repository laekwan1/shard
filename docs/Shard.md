# Shard

로컬 DPI/SNI 우회. **서버가 필요 없고 트래픽 경로가 바뀌지 않으므로 속도 손실이 사실상 없습니다.**

대신 **익명성은 전혀 제공하지 않습니다.** 접속하는 사이트는 우리 IP를 그대로 봅니다. 그쪽이 필요하면 Veil을 쓰세요.

## 실행

`shard.exe`를 실행합니다. 관리자 권한이 필요하며(커널 드라이버를 열어야 합니다) UAC가 뜹니다.

창 없이 트레이에만 올라옵니다 — **청록색 잘린 사각형** 아이콘입니다.

| 조작 | 방법 |
|---|---|
| 창 열기 | 트레이 아이콘 좌클릭 |
| 켜기/끄기 | 트레이 우클릭 메뉴, 또는 `Ctrl+Shift+S` |
| 종료 | 트레이 우클릭 → 종료 |

창을 닫아도 종료되지 않고 트레이로 내려갑니다.

## 어떻게 쓰는가

**이 창에서 사이트를 여는 게 아닙니다.** Shard는 PC에서 나가는 패킷을 커널에서 직접 손보기 때문에 크롬·게임·업데이터 가릴 것 없이 **모든 프로그램에 자동으로 적용**됩니다.

```
Shard 켜기  →  브라우저에서 평소처럼 접속
```

설정 안의 입력창은 접속용이 아니라 차단 여부를 검사하는 진단 도구입니다.

### 끄면 어떻게 되는가

**즉시 원래대로 돌아갑니다.** 우회는 연결이 맺히는 순간에만 일어나고 아무것도 남기지 않습니다.

다만 Shard가 손대는 것은 연결을 **여는** 첫 패킷뿐이라, 이미 맺혀 있는 연결은 끊길 때까지 그대로 살아 있습니다. 브라우저가 연결을 재사용하기 때문에 끈 직후 30초~1분쯤은 보던 탭이 계속 되는 것처럼 보일 수 있습니다. 새 연결부터는 다시 막힙니다.

학습한 도메인별 전략은 디스크에 남으므로, 다시 켜면 재학습 없이 곧바로 적용됩니다.

## 처음 할 일

**켜기. 그게 전부입니다.**

기본 전략이 대부분의 사이트를 처리하고, 그것으로 안 되는 곳은 Shard가 스스로 알아냅니다.

### 어떻게 알아내는가

차단은 두 가지 모습으로 나타나고, 둘 다 감지합니다.

| 신호 | 무엇 | 비용 |
|---|---|---|
| **리셋 주입** | 핸드셰이크 직후 RST가 날아옴 | 사실상 0 |
| **무응답** | 핸드셰이크를 보냈는데 아무것도 안 옴 | 인바운드 데이터 패킷을 봐야 해서 CPU 몇 % |

같은 호스트에서 실패가 기준 횟수(기본 2회) 쌓이면 백그라운드로 탐색을 시작합니다. 전략 사다리를 **비용이 싼 순서로** 올라가며 실제 TLS 핸드셰이크를 시도하고, 처음 성공한 조합을 그 도메인 전용으로 저장합니다. 이후 그 사이트는 계속 그 전략을 씁니다.

한 번의 리셋은 서버가 그냥 끊은 것일 수도 있어서 기준 횟수가 있습니다. 오탐이 나더라도 탐색이 먼저 "우회 없이도 되는가"를 확인하므로, 통하는 사이트에 불필요한 전략이 붙지 않습니다.

무응답 감지는 부담이 되면 끌 수 있습니다. 끄면 리셋을 주입하는 망에서만 자동 학습이 동작합니다.

### 수동 탐색

자동 감지를 기다리지 않고 특정 도메인을 지금 확인하고 싶으면, 상태 탭에 도메인을 넣고 **탐색 시작**을 누르세요.

## 부작용이 나면

전체 트래픽에 적용되는 것이 기본값이라, 분할에 예민한 사이트가 깨질 수 있습니다. 도메인 탭의 **예외 도메인**에 넣으면 범위와 무관하게 항상 통과시킵니다.

## 파일

| 파일 | 용도 |
|---|---|
| `shard.exe` | 본체 |
| `WinDivert.dll`, `WinDivert64.sys` | 커널 패킷 인터셉트 드라이버 |

세 파일이 **같은 폴더에** 있어야 합니다.

설정과 로그는 `%APPDATA%\Shard\`에 저장됩니다.
